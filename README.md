End-to-End Regional Sales Analysis

An end-to-end Data Analytics project focused on Regional Sales Analysis using Python, Exploratory Data Analysis (EDA), and Power BI.

This project demonstrates the complete analytics workflow from data collection and cleaning to dashboard development and business insight generation.

Project Overview

The objective of this project is to analyze regional sales data to identify:

Revenue and profit drivers
Product and channel performance
Regional sales trends
Customer behavior
Business growth opportunities

The project includes:

Data Cleaning
Data Transformation
Exploratory Data Analysis
Feature Engineering
Dashboard Development in Power BI
